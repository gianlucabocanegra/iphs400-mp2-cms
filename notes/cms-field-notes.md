# CMS field notes (WordPress Playground)

- I saved a post as a draft and it did not show up on the public site. Once I hit Publish, it showed up. Publishing took two clicks: one on the blue button, then a second to confirm.
- I made an "About" page and it went straight into the menu at the top. My post did not go in the menu. It showed up in a Blog list instead. So pages are for navigation and posts are like a feed.
- My post was dated Sept 29 even though it was still Sept 28 for me. WordPress used a different time zone (UTC), which was confusing.
- The slug is the last part of the web address, and WordPress makes it from the title. The default address also puts the date in it. There is a "Plain" option that gives ugly links like ?p=123.
- I made an Editor user and logged in as them. The Users, Settings, Plugins and Appearance links were gone from the left menu. The editor could still see Posts, Media, Pages, Comments, Profile and Tools.
- I typed the Users page address directly as the editor, and it said "You need a higher level of permission." So it is a real block, not just a hidden link.
- The All Posts screen shows Title, Author, Categories, Tags, Comments and Date. The links above it (All, Published) only show a status if a post has that status. My Drafts link disappeared once I had no drafts.
